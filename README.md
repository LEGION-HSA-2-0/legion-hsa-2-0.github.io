# LEGION: AI-Enabled Archaeology
### machine LEarninG-enabled Identification of archaeological Objects in the middle daNube river basin.

**LEGION** is a multi-disciplinary Heritage Science project that bridges the gap between archaeological expertise and advanced computational methods. The project focuses on decoding the history of Roman Carnuntum and the Middle Danube River Basin through the automated classification of common ware pottery using cutting-edge Machine Learning.

---

## 🚀 Key Innovation
Traditional classification of archaeological ceramics is often a manual bottleneck, leaving massive datasets unassessed. LEGION introduces:
*   **Semi-supervised Computer Vision Pipeline**: Leveraging thousands of historical documents and technical drawings for deep material insight.
*   **Human-in-the-Loop (HITL)**: Utilizing Explainable AI (XAI) to ensure results are validated by experts and remain archaeologically robust.
*   **High Accuracy**: Achieving >90% classification accuracy for automated typochronological dating.

## 🏺 Research Impact
*   **Socio-Economic Insights**: Revealing complex patterns in local production and tracking trade trends.
*   **New Typochronology**: Establishing a data-driven typochronology of Roman Common Ware based on large-scale analysis.
*   **Open Source Tools**: Providing a user-friendly, free tool for the global research community.

## 🛠 Tech Stack
*   **Frontend**: Modern, responsive web interface built with HTML5, Vanilla CSS3, and Javascript (ES6+).
*   **3D Visualization**: [Google Model Viewer](https://modelviewer.dev/) for interactive, performance-optimized GLB assets.
*   **AI/ML Pipeline**: Python-based computer vision models leveraging semi-supervised learning.
*   **Vibe Coding**: Developed using the agentic platform **Google Antigravity**.
